# HEH-Code

**Live:** https://code.chausima.com

A reader for the code behind the Homework Launchpad: pick a part of the
Launchpad and browse its files, straight from GitHub, without needing an
account.

It only shows public repositories. The server side (sign-in checks, the
filter and the AI keys) isn't public, so it isn't here either. See the
[HEH-Homework README](https://github.com/silocell/HEH-Homework) for why.

Plain HTML, CSS and JavaScript, hosted on GitHub Pages.
